## Configuration

| Variable/Flag | Purpose | Required |
|---------------|---------|----------|
| `CROSSPOINT_VERSION` | 펌웨어 버전 문자열 | yes (빌드 시 자동) |
| `ENABLE_SERIAL_LOG` | 시리얼 로깅 활성화 | no (dev/rc에서 활성) |
| `LOG_LEVEL` | 로그 레벨 (0=error, 1=info, 2=debug) | no |
| `EINK_DISPLAY_SINGLE_BUFFER_MODE` | e-ink 단일 버퍼 | yes |
| `XML_GE` / `XML_CONTEXT_BYTES` | expat XML 파서 설정 | yes |
| `USE_UTF8_LONG_NAMES` | SdFat UTF-8 파일명 | yes |
| `PNG_MAX_BUFFERED_PIXELS` | PNG 스캔라인 버퍼 (2048px) | yes |
| `platformio.local.ini` | 로컬 빌드 오버라이드 | no |
