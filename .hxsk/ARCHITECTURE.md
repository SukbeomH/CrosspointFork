# Architecture

> Generated by /map on 2026-04-08

## Overview

CrossPoint Reader는 **Xteink X4** e-paper 디바이스를 위한 오픈소스 펌웨어.
**ESP32-C3** MCU + **PlatformIO** (Arduino framework) 기반 C++ 프로젝트.
Activity 기반 앱 아키텍처, SD 카드 캐싱, e-ink 최적화 렌더링 파이프라인으로 구성.

## Components

### Main Runtime (`src/main.cpp`)
- **Purpose:** 부트, 하드웨어 초기화, 폰트 로딩, Activity 전환, 메인 루프, deep sleep
- **Location:** `src/main.cpp`
- **Key globals:** `display`, `gpio`, `renderer`, `currentActivity`, `mappedInputManager`

### Activity Layer (`src/activities/`)
- **Purpose:** 화면 단위 컨트롤러. `Activity` 베이스 클래스 상속, FreeRTOS 렌더 태스크 사용
- **Base:** `Activity.h` (onEnter/onExit/loop/render, RenderLock RAII 뮤텍스)
- **Groups:**
  - `boot_sleep/` — BootActivity, SleepActivity
  - `home/` — HomeActivity, MyLibraryActivity, RecentBooksActivity
  - `reader/` — ReaderActivity, EpubReaderActivity, TxtReaderActivity, XtcReaderActivity + 메뉴/챕터 선택
  - `settings/` — SettingsActivity, FontSelection, OtaUpdate, ButtonRemap, KOReader, Language 등 14개
  - `network/` — WiFi 선택, AP/STA, Calibre, CrossPointWebServer
  - `browser/` — OpdsBookBrowserActivity
  - `util/` — FullScreenMessage, KeyboardEntry, BmpViewer

### Settings & State (`src/`)
- **CrossPointSettings.h** (`SETTINGS` 싱글톤): 사용자 환경설정 (폰트, 레이아웃, WiFi, 언어 등)
- **CrossPointState.h** (`APP_STATE` 싱글톤): 런타임 상태 (현재 책, 읽기 위치, sleep 컨텍스트)
- **JsonSettingsIO**: JSON 기반 설정 직렬화
- **Persistence:** SD `/.crosspoint/` 디렉토리에 바이너리 캐시

### Network (`src/network/`)
- **CrossPointWebServer:** HTTP(80) + WebSocket(81) 서버. 파일 업로드/관리, 설정 API
- **OtaUpdater:** OTA 펌웨어 업데이트 (GitHub releases에서 다운로드)
- **HttpDownloader:** HTTP 파일 다운로드 유틸리티
- **WebDAVHandler:** WebDAV 프로토콜 지원

### Content Libraries (`lib/`)
- **Epub:** EPUB 파싱 (OPF, TOC, CSS), 레이아웃, 하이픈 처리. 가장 큰 라이브러리
- **Xtc/Txt:** XTC, TXT 포맷 리더
- **GfxRenderer:** e-ink 디스플레이 렌더링 엔진 (텍스트, 이미지, UI)
- **EpdFont:** 폰트 압축/디코딩
- **I18n:** 다국어 지원
- **Utf8:** UTF-8 문자열 처리
- **Others:** ZipFile, InflateReader, PngToBmpConverter, JpegToBmpConverter, picojpeg, uzlib, expat(XML), OpdsParser, KOReaderSync, Serialization, FsHelpers, Logging

### HAL (open-x4-sdk)
- **Purpose:** 하드웨어 추상화 (서브모듈, 현재 비어있음 — symlink로 참조)
- **Components:** HalDisplay, HalGPIO, HalPowerManager, HalStorage
- **SDK Libraries:** BatteryMonitor, InputManager, EInkDisplay, SDCardManager

### UI Components (`src/components/`)
- **UITheme:** 테마 시스템
- **BaseTheme → LyraTheme / Lyra3CoversTheme:** 구체적 테마 구현
- **icons/:** 아이콘 헤더 (book, cog, folder, wifi 등 16개)

## Data Flow

```
User Input (Buttons)
  → MappedInputManager (GPIO → 논리 입력)
  → Activity.loop() (입력 처리)
  → State Update (APP_STATE, SETTINGS)
  → render() → GfxRenderer → HalDisplay → E-ink Refresh

Book Loading:
  SD Card → Epub/Xtc/Txt parser → Section Cache (SD) → GfxRenderer

Network:
  WiFi (STA/AP) → WebServer → SD Card (파일 업로드/다운로드)
  OTA: GitHub API → HttpDownloader → ESP32 OTA partition
```

## Conventions

- **Naming:** PascalCase (클래스/파일), camelCase (변수/메서드), UPPER_CASE (상수/매크로)
- **Structure:** Activity 패턴 (onEnter/onExit/loop/render), 기능별 디렉토리 분리
- **Testing:** PlatformIO native 테스트, 하이픈 처리 평가 테스트 (`test/hyphenation_eval/`)
- **Build:** PlatformIO + pre-build 스크립트 (HTML 생성, i18n 생성)
- **Logging:** `LOG_DBG/LOG_ERR` 매크로 (태그 기반, 레벨 설정 가능)
- **Thread Safety:** FreeRTOS 뮤텍스 (RenderLock RAII)
